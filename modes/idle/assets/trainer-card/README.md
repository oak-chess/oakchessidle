# Arte do cartão

Moldura, emblema VIP e atlas de ícones gerados para este painel a partir do modelo visual aprovado nesta conversa. Textos e valores de jogador são inseridos pela interface. `backplate-v1.webp` é a versão compactada da moldura; os dois PNGs preservam transparência. Os retratos de Pokémon são carregados separadamente dos sprites do jogo.
